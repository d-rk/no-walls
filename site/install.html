Firefox-Erweiterung: Bei Artikeln hinter einer Paywall erscheint unten rechts ein Button „Ganzer Artikel“, der die archivierte Version auf archive.is öffnet.

In Firefox installieren

So geht's (Firefox auf Android oder Desktop):

  1. Diese Seite in Firefox öffnen und auf den Button tippen.
  2. Falls Firefox fragt, ob diese Seite Erweiterungen installieren darf: Erlauben.
  3. Hinzufügen bestätigen. Fertig – Updates kommen automatisch.

Klappt das Antippen auf Android nicht: Datei herunterladen, dann in Firefox Einstellungen → Über Firefox, 5× aufs Logo tippen, zurück in die Einstellungen → Add-on aus Datei installieren und die heruntergeladene Datei wählen.

Chrome wird nicht unterstützt.
