No Walls

Firefox-Erweiterung: Bei Artikeln hinter einer Paywall erscheint unten rechts ein Button „Ganzer Artikel“, der eine frei lesbare Version öffnet.

Bitte diese Seite in Firefox öffnen – andere Browser werden nicht unterstützt.

In Firefox installieren
  1. Auf den Button klicken.
  2. Falls Firefox fragt, ob diese Seite Erweiterungen installieren darf: Erlauben.
  3. Hinzufügen bestätigen. Fertig – Updates kommen automatisch.
1. Herunterladen
  1. Auf den Button tippen und Herunterladen bestätigen.
  2. Firefox-Menü ⋮ → Einstellungen → ganz unten Über Firefox → 5× auf das Firefox-Logo tippen (nur beim ersten Mal nötig).
  3. Zurück zu Einstellungen → Add-on aus Datei installieren.
  4. no-walls.xpi aus Downloads wählen und Hinzufügen bestätigen.

Fertig – Updates kommen danach automatisch.
